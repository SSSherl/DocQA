## 一、先纠正：初稿里 6 处与代码不符

| 初稿说法 | 代码事实 | 出处 |
| --- | --- | --- |
| 「四个页面」 | 实际是 **3 个页签**（智能问答 / 文档知识库 / 服务状态）+ 左侧会话历史 + 右侧参考资料面板 | `web/index.html` |
| 「知识约定 = AGENTS.md」 | 运行时读的是 `knowledge_contract.md`，由 `agent.py` 显式读取；AGENTS.md 只约束开发 | `agent.py:38` |
| 「四种状态」 | 实际 **五种**：model / extractive / no_evidence / citation_rejected / interrupted | `agent.py`、`index.html` badge |
| 「三路召回」 | BM25、稠密、BGE 补充稠密之外，还有 **图文向量**（第 4 路），本地稀疏可再叠加 | `docbase.py:222-274` |
| 「Agent 自主补查」 | 只有一次**有界**补查：命中 < 2 条时抽英文术语再查，最多 2 轮，其余是固定流程 | `agent.py:19-26` |
| 「147 页 PDF 证明稳定」 | 是合成文档 + 故障模拟，不等于任意 PDF；且本次发布未调真实云端 API | `docs/验收测试清单.md` |

另外两个可以放心写上大屏的数字（都能在代码里指到）：

- **BM25 是手写的**：中文按「单字 + 二元组」切词，不依赖分词器，`k1=2.5, b=0.75`（`docbase.py:16-22, 210-214`）
- **融合是加权 RRF**：`score = Σ w/(60+rank)`，BM25 默认权重 2.0（`config.example.json`、`docbase.py:275-283`）

## P9 · 第三步 问答

**标题**：先查再答，答不出就说答不出
**配图**：左侧流程（提问 → 检索 → 证据够吗？不够则虚线回环一次 → 综合）；右侧一道「闸门」：答案 → 检查 `[n]` 是否都在本次来源内 → 通过 ✓ / 拦下 ✕。

- 五种状态：模型综合 / 原文摘录 / 暂无证据 / 引用未通过 / 已停止

## P12 · 创新二

**标题**：创新二：换模型，不让索引对不上号
**配图**：左「① 验证候选」→「② 算指纹」→ 一竖分三叉 → 三路汇入「③ 原子切换」，底部一条虚线回滚箭头指回起点。
```
①验证候选 → ②算指纹 ┬ 无需重建（只换 Chat/精排）─┐
                      ├ 只刷向量（正文和编号不动）─┼→ ③原子切换
                      └ 临时重建（新目录，成功才用）─┘
                                    ↑
             任一步失败 → 旧配置、旧索引原样可用（虚线）
```
**文字**：
- 先验证模型，5 分钟内的成功结果可直接复用
- 只换 Chat / 精排 → 根本不用重建
- 只换向量模型 → 只刷向量，正文和引用编号不动
- 换了视觉模型 → 临时目录重建，成功才切换
- 任一步失败 → 旧配置、旧索引原样可用

**画法要点**：六个圆角矩形 + **肘形连接符**（不是直线）。B 的右边留 2cm 空白，三条分支线会自动叠成「一竖三分」；三条分支各连一条到 C，自动叠成汇聚。回滚线用肘形连接符 + 虚线 + 末端箭头。配色只用两种：蓝=正常路径，橙=代价最高的分支，灰=无需动作。

## P13 · 创新三

**标题**：创新三：147 页的 PDF，断了也能接着来
**配图**：**泳道图**，上下两条泳道，中间夹一条虚线文件条。
```
┌ 网页 · 主进程 ────────────────────────┐
│  [接收原件]   [写任务文件]   [轮询进度] │
└───────────────┬───────↑───────────────┘
        ┌───────↓───────┴───────────────┐
        │ state.json · 唯一交接点（虚线） │
        └───────┬───────↑───────────────┘
┌───────────────↓───────────────────────┐
│ 导入 · 独立子进程                      │
│  [解析文档与图片] [生成各类向量] [提交索引] │
└───────────────────────────────────────┘
出错时：[原件回滚保留] [旧索引不动] [一键重试复用缓存]
```
**文字**：
- 导入跑在独立子进程，网页不卡死
- 任务状态落盘（原子替换），刷新、重启都看得见
- 失败：原件保留 + 旧索引不动 + 一键重试
- 重试复用缓存：只缓存成功结果，键里带模型身份

**讲解要点**：两条泳道之间**没有一根直接连线**，只有一个虚线框文件——这就是"网页为什么不卡"的全部答案。

**不要说的话**（技术文档 8.3 节自己划的红线）：

- ❌ 首创 RAG 与 Agent 融合 → ✅ 把已有技术整合成本地文档工作流
- ❌ 云端 BGE-M3 就是学习型稀疏 → ✅ 云端是补充稠密，本地稀疏另行启用
- ❌ 引用检查确保答案正确 → ✅ 检查来源编号合法，并提供原文复核入口
- ❌ 完全本地、资料绝不上云 → ✅ 数据本地保存，远程模型经允许后接收必要内容
- ❌ 147 页证明任意 PDF 不会断 → ✅ 指定合成场景与故障条件下通过验收

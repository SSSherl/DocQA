# DocQA 需求规格说明书

## 目标与边界

面向个人的本地多模态文档知识库，支持资料导入、可选模型检索与问答、来源追溯。默认仅本机访问；不提供公开互联网多用户账户体系。发布版不附带模型密钥、个人资料或索引。

## 功能

1. 导入 PDF、DOCX、PPTX、MD、TXT、PNG、JPG/JPEG，单文件最多25MB。旧DOC/PPT需先转换。Word通过标题引用，PPT通过幻灯片引用；不虚构物理页码。
2. 解析产生Markdown、来源元数据和图片。未配置视觉模型时明确提示图片未解读；PPT原生组合图形建议转PDF。
3. 按标题/段落和长度切块，保留重叠及真实来源。内容和配置指纹控制增量更新；失败保留旧索引。
4. BM25默认可用；可按实际服务配置稠密向量、BGE补充稠密、图文向量及真正的本地BGE-M3稀疏通道。经RRF融合，可选精排。不得用BM25或伪造向量冒充模型输出。
5. 支持分类和Top K。精确型号/接口保留字母、数字、下划线。过期索引拒绝混用；模型通道失败有明确提示并回退。
6. Agent先检索、必要时补查，再整理证据和综合回答。未配置Chat返回原文摘录。模型回答需使用本次来源编号；编号检查不代表事实语义已验证。
7. Markdown与来源摘录安全渲染，Mermaid本地渲染、源码切换、复制、SVG下载、放大；非法图表保留代码。
8. PDF引用打开真实对应页，按精确文字匹配高亮，支持翻页、跳页、缩放、原件下载。图表解读或无法匹配时只定位页。
9. Chat支持SSE时边生成边显示，最终检查引用。停止生成关闭上游连接并保留明确标记的未完成内容；重新回答复用原问题设置、保留旧版本。
10. 会话保存在本机，可恢复、切换单轮或删除。同会话最近四轮辅助理解追问；历史回答不是本次事实证据，未完成回答不用于后续上下文。
11. 后台可扫描指定目录、处理新增或变化文件。监控与数据目录不得互相包含。删除原文件不会自动删除索引。
12. 人工标注的评测集支持Recall、Hit Rate、MRR、无答案项和耗时对比。示例结果不作为普遍质量承诺。

## 架构

依赖方向：web/service → agent → docbase → doc2md；models/streaming提供模型协议边界。代码与数据分离。

- doc2md：parse_document，生成Markdown、manifest和图片。
- docbase：build、query、evaluate，管理索引及来源。
- agent：answer_question，检索、上下文、证据和引用检查。
- service：目录监控和增量处理。
- web：本地界面、导入、问答、会话、PDF和模型状态。

## 配置与接口

所有模型默认停用，地址、模型名及密钥由使用者提供。密钥从环境变量或Windows当前用户加密凭证读取，配置不保存明文密钥。远程调用需显式允许，届时会发送相关文本或图片至配置服务。

服务状态页提供六个独立配置入口：Chat、Vision、Embedding、Reranker、BGE-M3、图文向量。支持接口地址、模型名、密钥、启停、超时、可选维度和环境变量绑定。密钥默认以星号占位，点击右侧眼睛可显示，再次点击隐藏；仅主动点击时读取已保存密钥，收起卡片时自动隐藏。留空保留，填写后替换，也可清除绑定。测试连接不保存配置；保存先验证，涉及解析或向量变化时重建临时索引，成功后生效，无需重启，失败保留原配置和索引。测试和重建可能产生服务商 API 费用。

Chat/Vision使用chat-completions格式；流式回答要求SSE；向量使用embeddings格式；精排使用rerank格式。图文输入兼容性须单独验证。云端BGE稠密向量与本地学习型稀疏模型必须明确区分。

## 验收与限制

- 未配置模型能导入文字、检索并展示原文，不声称已完成语义综合或图片解读。
- 更新失败不覆盖有效索引；分类过滤在召回前执行；来源可追溯。
- 上传路径、大小、来源访问和同源请求受校验；资料中的指令只作内容，不能改变系统约定或执行代码。
- 本地历史、密钥和文档不进入发布包。恢复历史时重新清洗HTML，模型引用最终检查。
- 测试覆盖解析、索引、协议、回退、引用、PDF定位、SSE与取消。运行 python -m pytest -q。
- 不承诺固定响应时间、任意规模性能、所有复杂追问的消歧准确率或模型生成图的事实正确性。

## 入库性能与任务反馈

导入提供后台任务和可轮询阶段进度，浏览器刷新不取消任务。图片解析及向量请求最多两个并发，文本向量每批最多8条；临时错误至多一次重试，鉴权与限流错误不盲目重试。成功推理结果按内容和模型身份缓存在本机数据目录，重试复用；失败保留已启用索引和原文件，不把缓存或私有资料打入发布包。

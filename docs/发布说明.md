# 发布与使用说明

本发布包保留公开模型 URL、模型名、超时和向量维度，不含 API 密钥或本机凭证绑定。六个模型默认停用，远程调用默认关闭；由接收者在“服务状态”填写自己的密钥、启用通道并验证保存。

包内仅含源码、配置示例、部署手册、测试和合成示例，不含个人文档、索引、会话、模型缓存、私人截图、虚拟环境或私人备份。详细步骤见 [部署手册](部署手册.md)。

Windows 运行 `start.ps1`。首次启动自动从 `config.example.json` 创建本人的 `config.json`。服务地址默认为 http://127.0.0.1:8765，仅绑定本机；源码发布不等于完成公网多用户部署。

本版包含入库缓存与进度、快速连接验证、默认勾选的待启用选项、密钥显隐，以及位于“验证并保存”按钮右侧的绿色验证标记。测试文档为 `examples/项目说明.md`，不配置 API 也可先验证文字检索流程。

本次修复验证失败时输入密钥被提前清空的问题：失败保留输入，卡片内显示原因；远程调用未允许时先提示；成功保存后才切换为星号。每次交付前对解压包执行验收，详见 [验收测试清单](验收测试清单.md)。

本次重新发布清空了全部配置示例的凭证和环境变量绑定；公开 URL 和模型名保留。全新解压启动的六个模型通道均无密钥。若在旧目录覆盖安装，旧 config.json 仍属于原有个人配置；请使用新的解压目录，避免误认为旧凭证来自发布包。

本次修复大文档上传期间网页阻塞：网页导入使用独立进程和持久任务状态；模型请求默认直连、不继承系统代理；截断响应转为可重试连接错误，重试采用有界指数退避。失败原件可一键重试，已有原文和索引保留。发布验收新增合成 147 页、17 幅图的 PDF，覆盖慢模型、截断响应、失效代理环境、服务重启和失败重试。内部问题报告不在发布包中。

Windows 多进程替换任务状态文件时的短暂共享冲突采用有界等待处理，避免将文件切换瞬间误报为网页断联。
